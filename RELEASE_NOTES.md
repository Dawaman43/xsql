# Draft release notes — v0.1.0

This is a draft for the initial v0.1.0 release.

Highlights
- Interactive TUI for conversion and folder-batch conversion
- Support for MySQL, PostgreSQL, and SQLite schema DDL (CREATE TABLE)
- Bidirectional conversion between dialects via an intermediate representation
- One-line installer script for quick setup

Known limitations
- Only CREATE TABLE is fully supported; indexes and advanced constraints may be lossy.

Breaking changes
- None expected for v0.1.0.
